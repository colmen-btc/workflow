# EDI Product Documentation

This repository maintains product documentation, initiatives, and planning artifacts for the **EDI (Energy Data Intelligence)** product suite.

## Repository Structure

```
product-docs/
├── architecture/          # System architecture diagrams and documentation
├── initiatives/          # Product initiatives and feature planning
│   ├── edi-data-intelligence/
│   ├── mcp-server-hardening/
│   └── ...
├── openspec/            # OpenSpec-based change proposals
│   ├── changes/         # Active and archived changes
│   └── specs/           # Specification library
└── ...
```

## What's Inside

- **Initiatives**: Comprehensive planning documents including product briefs, PRDs, UX specifications, and technical designs
- **Architecture**: System-level architecture diagrams, component designs, and ADRs (Architecture Decision Records)
- **OpenSpec Changes**: Spec-driven development artifacts for features and enhancements

## Purpose

This repository serves as the central hub for:
- Product planning and requirements definition
- Initiative tracking and documentation
- Technical architecture and design decisions
- Cross-functional collaboration artifacts

## Related Repositories

- **Code Workspace**: Implementation artifacts live in the sibling code repository
- **Multi-root Workspace**: Open `edi-initiative.code-workspace` in VS Code for unified access to both planning and code

## Workflow

1. **Planning**: Initiatives and OpenSpec changes define what to build
2. **Design**: Architecture and technical specifications document how
3. **Implementation**: Code workspace contains the actual implementation
4. **Documentation**: This repository remains the source of truth for planning context
